There's an inverse law nobody warned us about: the more intelligent the
system, the harder it is to design. A button that does one thing is easy to
make trustworthy. A model that can do almost anything — sometimes brilliantly,
sometimes confidently wrong — is not.

For decades, trust in software came for free with predictability. Same input,
same output, every time. Design was mostly a clarity problem: label the
button well and the interface kept its promises by construction. Intelligent
systems broke that deal. The output is probabilistic, so the interface can no
longer promise *what* will happen — only how it will feel when it does.

That makes the emotional layer the actual design surface. How confident
should this answer look? When should the system hesitate, show its work,
ask instead of act? Overstate certainty and you burn trust on the first
mistake; understate it and nobody uses the thing at all. Conveying the right
emotions — trust, confidence, appropriate doubt — is harder now than it has
ever been.

The irony is that as the systems get smarter, the design work gets more
human. Less arranging pixels, more deciding what a machine should sound like
when it isn't sure.
