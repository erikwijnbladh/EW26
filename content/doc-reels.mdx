Paste a documentation URL, get five vertical reels — voiceover, word-by-word
subtitles, gameplay footage behind. A joke that turned out to be about timing.

Press play, then drag the slider.

<SubtitleSync />

That's why it can't be a `setInterval`: speech has no fixed rate, so a schedule
drifts and the error compounds. The timing comes from character-level
timestamps in the speech API instead, folded into words — the player asks which
word's start has most recently passed, every frame. Nothing to drift from.

Without an API key it still runs. Word durations get estimated from length and
the clock falls back to `performance.now()` — silent, but the subtitles still
land. That's the version above.

<Image src="/images/docreels-player.jpg" alt="The Doc Reels player — a 9:16 frame with a five-segment progress bar, title overlay and play control" />

Started as Bun and Elysia with Remotion compositing video, then got rebuilt once
it was clear the browser could do all of it — a `<video>`, an `<audio>`, and a
clock. The public repo is that first version.
