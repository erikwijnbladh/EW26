Like a lot of people, most of my design work happens in agents now. I don't
keep a Figma system in sync any more, and I don't sketch states I'm going to
rebuild in code an hour later. It's faster, and mostly it's better.

The place it stops working, for me, is anything shared.

If I change a padding value on the button every other button is built from, I
can't see what that did. I can look at the button. I can't look at the toolbar
and the form and the empty state at the same time, which is where the change
actually lands. So I go and check them one by one, or I don't, and I find out
in review.

Tools like Storybook show a component on its own. That's the right idea for
looking at one thing and the wrong idea for looking at a system, because a
system is mostly relationships and a relationship doesn't fit in one frame.

## What I built

A canvas that puts the components on screen together, running for real, and
updates all of them as I type.

The workspace has a `Toolbar` that deliberately uses five different cases of
the same root button — icon-only, disabled, loading, danger, primary with text.
So editing one class in the button's base string moves five real usages across
two panes at once. Not a preview: those buttons, in the places they're used.

That's the whole thing, honestly. Everything else is plumbing.

## Two decisions I'd keep

**Components stay ordinary `.tsx` files on disk.** Nothing is exported or
synced, and there's no format to convert out of. Git works, imports work, my
editor works, and agents work without knowing Pane exists. If I stop using it
tomorrow I lose nothing, which is roughly the bar I want a tool like this to
clear.

**No save step.** I noticed that when checking a change costs a save and a
rebuild, I stop making the ones I'm not already fairly sure about — and those
are the ones that teach you something. Making it free changed what I was
willing to try, more than it changed how fast I worked.

## What it doesn't do

It's a local thing for one person. There's no collaboration, no versioning
beyond git, and the hosted demo runs a cut-down in-browser build with no dev
server behind it, so edits there don't persist.
