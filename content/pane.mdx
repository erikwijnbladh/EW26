An infinite canvas for developing React components visually, while keeping each
component a real `.tsx` file on disk.

The workflow is built around spatial organization, live previews, Vite HMR, and
CodeMirror editing — everything stays local-first. It's an exploration of how
design systems and component development can become more visual and iterative.
